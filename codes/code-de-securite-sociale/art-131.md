# Article 131

Les tribunaux de premiére instance sont cornpétents pour juger de toute contestation s'élevant entre les bénéficiaires des dispositions de la présente loi, les employeurs et la Caisse.
Les règles de procédure applicables sont celles prévues par les dispositions du code du travail.
