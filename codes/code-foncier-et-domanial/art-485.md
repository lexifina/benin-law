# Article 485

Tous les équipements de traitement des données numériques, les réseaux, les programmes ainsi que les divers appareillages, doivent être maintenus dans un environnement contrôlé,, conformément aux normes industrielles exigées. Tous ces systèmes doivent être protégés contre les virus, les messages non sollicités, les pirates de ligne et toutes autres intrusions non autorisées.
