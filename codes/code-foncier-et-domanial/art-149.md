# Article 149

Les bureaux communaux du domaine et du foncier sont dotés de registres fonciers dans lesquels les droits sujets à inscription conformément au présent code sont enregistrés. Chaque bureau garde le nombre de registres nécessaires pour y inscrire les propriétés relevant de sa compétence. Les registres fonciers contiennent les informations prescrites par le présent code et toutes autres informations relatives à la confirmation des droits fonciers.
