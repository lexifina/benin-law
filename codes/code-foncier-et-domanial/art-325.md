# Article 325

Sous peine de sanctions prévues par les textes en vigueur, le parcours d’animaux domestiques est interdit :
dans les forêts classées ;
dans les forêts protégées, lorsque le parcours présente un danger pour les espèces botaniques ou pour la préservation de la forêt ;
dans les périmètres de restauration ;
sur les terrains repeuplés artificiellement ou reboisés ou portant des boisements de moins de cinq (5) ans.
