# Article 471

La procédure de confirmation de droits fonciers collective, coordonnée par les bureaux déconcentrés de l’organe en charge de la confirmation de droits fonciers comporte les étapes suivantes :
identifier, lever, et marquer les limites administratives ;
identifier toutes les terres, leurs situations, forme, description, basée sur les actes juridiques ou à défaut, basée sur la déclaration du propriétaire foncier ;
enregistrer tous les conflits fonciers en instance devant les tribunaux ; créer tous les documents officiels du cadastre ;
accomplir les formalités de publicité pendant trente (30) jours ;
enregistrer simultanément les données au cadastre et au registre foncier.
