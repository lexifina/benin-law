# Article 966

Le défendeur doit y répondre dans le délai d'un (Dl) mois, faute de quoi la pièce est écartée des débats.
! La pièce est également écartée si la réponse est négative.
Si la réponse est affirmative, elle est portée à la connaissance du demandeur à l'incident dans le délai de quinze (l5) jours.
Le président renvoie alors les parties à se pourvoir devant telle juridiction qu'il désigne pour procéder au jugement de faux.
