# Article 1054

Le tribunal statue sur ces comptes dans les deux (02) mois du dépôt fait au greffe.
Le jugement est rendu sur les conclusions du ministère public.
Le curateur peuL dans les trois (03) mois, se pourvoir par requête devant la cour d'appel qui se prononce, dans 10 même forme et dans le même délai, sur le rapport d'un conseiller.
Les comptes du curateur apurés par les tribunaux ne peuvent être attaqués par les ayants droit que pour erreur de calcul. omission, faux ou double emploi.
