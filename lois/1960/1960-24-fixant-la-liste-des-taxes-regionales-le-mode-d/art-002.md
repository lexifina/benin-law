# Article 2

Les conseils généraux peuvent instituer les taxes ou contributions à caractère fiscal énumérées ci-après qui seront applicables à compter du 1er janvier 1961.
1° Taxe de circonscription ;
2° Taxe de voirie ;
3° Taxe de pacage ;
4° Taxe sur les pirogues ;
5° Taxe sur les bicyclettes ;
6° Taxe de stationnement ;
7° Droit de place dans les marchés, fêtes et foires ;
8° Droits d’expédition de conventions coutumières ;
9° Droits d’expédition de jugements supplétifs ;
10° Taxe sur les spectacles et manifestations ;
11° Taxe sur les ventes des boissons fermentées de préparation artisanale.
