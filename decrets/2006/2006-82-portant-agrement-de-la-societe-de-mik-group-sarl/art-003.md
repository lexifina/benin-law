# Article 3

Les éléments à exonérer sont :
- quatre (04) malaxeurs ;
- deux (02) remplisseuses ;
- quatre (04) pompes à eau avec moteurs ;
- deux (02) chaudières à vapeur et accessoires ;
- trois (03) pompes à soude ;
- quatre (04) pompes à alcalis ;
- trois (03) pompes à savon de filtrage ;
- deux (02) fours ;
- cinq (05) cuves à niveau ;
- trois (03) machines à coudre ;
- cinq (05) échangeurs de chaleur ;
- deux (02) machines de fermeture d'emballages en plastique ;
- deux (02) paires de séparateurs de poudres (cyclones) ;
- deux (02) balances électroniques ;
- deux (02) paires de condenseurs barométriques ;
- une (01) pompe à vide ;
- deux (02) tableaux électriques de commande des machines et accessoires ;
- une (01) pompe doseuses à Parfum ;
- quatre (04) groupes électrogènes ;
- deux (02) lots d'outils (clés, tournevis, etc.) ;
- un (01) lot de fer, tôles, tubes, boulons, vannes etc. ;
- un (01) lot d'accessoires pour vapeur (baromètre, pressionstat, vannes etc.) ;
- deux (02) camions semi-remorque de 15 tonnes ;
- un (01) véhicule PICK UP double cabine TOYOTA ;
- deux (02) chariots élévateurs manitou ;
- un (01) lot de pièces de rechanges.
