# Article 3

Les éléments à exonérer sont :
- deux (02) scies à ruban horizontal ;
- deux (02) scies à ruban normal ;
- deux (02) scies à cadre ;
- une (01) scie circulaire double ;
- une (01) scie circulaire simple;
- une (01) scie multilames ;
- une (01) raboteuse ;
- une (01) ponceuse ;
- deux (02) dégauchisseuses ;
- deux (02) tronçonneuses ;
- une (01) toupie ;
- une (01) affrteuse de lame ;
- un (01) compresseur ;
- un (01) groupe électrogène ;
- un (01) lot de divers autres matériels ;
- un (01) tracteur ;
- un (01 ) chariot élévateur ;
- quatre (04) camions avec remorque ;
- un (01) lot de pièces de rechange.
