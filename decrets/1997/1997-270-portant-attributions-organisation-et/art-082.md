# Article 82

Les Organismes rattachés au Ministère des Finances sont Ies suivants :
- la Banque Centrale des Etats de l'Afrique de I'Ouest ( B C E A O ) ;
- le Fonds Africain de Garantie et de Coopération Economique ( F A G A C E ) ;
- le Centre National de Formation Comptable ( C E N A F O C ) ;
- le Campus Coopérative Bénin ( C C B )
