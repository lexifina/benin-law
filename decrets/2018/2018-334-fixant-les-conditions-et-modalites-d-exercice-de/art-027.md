# Article 27

Les autorisations d'exploitation suivantes sont instituées pour les lignes de production comme suit :
a) pour la production de semences d'une espèce donnée d'organisme aquatique autorisation d'exploitation d'unité de production de semences de l'espèce ;
b) pour la production de tailles marchandes d'une espèce donnée d'organisme aquatique : autorisation d'exploitation d'unité de grossissement;
c) pour la production d'aliments aquacoles: autorisation d'exploitation d'unité de production d'aliments aquacoles.
