# Article 17

La classification additionnelle adoptée est la classification par type de budget. Elle permet d'identifier le budget général, les comptes spéciaux du trésor et les budgets annexes. Elle constitue une codification additionnelle à la classification administrative et se codifie ainsi qu'il suit :
'1 : Budget général ;
2 : Budgets annexes ;
3 : Comptes spéciaux du trésor.
