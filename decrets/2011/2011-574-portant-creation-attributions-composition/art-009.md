# Article 9

Les membres représentant les Organisations Non Gouvernementales sont désignés comme suit :
Partenariat National de l'Eau du Bénin : un (1) représentant ;
Organisations Non Gouvernementales exerçant dans le domaine de l'environnement : un ('l ) représentant ;
Organisations Non Gouvernementales exerçant dans le domaine de la pêche : un (1 ) représentant ;
Organisations Non gouvernementales exerçant dans le domaine de I'agriculture : un (1) représentant ;
Organisations non Gouvernementales exerçant dans le domaine de l'élevage : un (1) représentant.
