- un (01) four à sol Bongard;
- une (01) fabrique de crème glacée ;
- un (01) élévateur à ciseaux ;
- une (01) diviseuse mercure;
- un (01) laminoir sur table ;
- une (01) façonneuse;
- un (01) batteur mélangeur ;
- deux cent (200) mètres toiles à couche ;
- une (01) armoire de fermentation ;
- deux (02) vitrines ;
- un (0i) comptoir à caisse ;
- une machine à glace alimentaire ;
- deux (02) lots d'ustensiles pour pâtisserie ;
- un (01) groupe électrogène ;
- un (01) véhicule fourgonnette 4CV ;
