# Article 3

Les étéments à exonérer sont :
Equipements de production
- une machine à onduter, spéciatement conçue Pour l'ondutation des feuiltes de tôles entièrement galvanisées de mesure attant jusqu'à 16' ;
- deux chaînes transporteuses de routeaux de capacité 30 tonnes ;
- deux ponts routants (spec : 20t x 72.200m span n'1 3228 hs code : 8426.1 100'00) ;
- vingt cinq tonnes de rampe CR'80 avec tous ses accessoires ;
- trois mitte cinq cent mètres carrés de feuitles transparentes FPR de 2.0mm avec des fits en acier ;
- cent fenêtres et cadres en acier de 1.5 MTR x 2.0 MTR ;
- une machine de modétisation de fer à béton avec accessoires ;
- une machine à étirer et à couper ;
- deux ponts bascutes étectriques ;
- une grue de 12D de marque ACE ;
- un étévateur diesel à fourches de capacité 12 T de marque GODREJ ;
- un groupe étectrogène 450 KVA ;
- un lot de pièces de rechange pour les équipements de production.
Matériel roulant
- deux camions bernes de 30T ;
- deux camionnettes NISSAN pick-up ;
- trois chariots élévateurs de 3 à 12 tonnes.
